# Portal-7-ano-A-
“Portal da Turma é um site interativo criado para facilitar a organização dos alunos, reunindo em um só lugar os deveres de casa, atividades, trabalhos, provas, avisos e conteúdos das aulas. O objetivo é ajudar os alunos a acompanharem suas responsabilidades escolares, inclusive quando faltarem à escola.”
